# 🎓 Student Management App

A simple application to manage students using CRUD operations.

## 🚀 Features
- Add student
- Edit student
- Delete student
- View list of students

## 🛠️ Technologies
- React / Node.js / Express (حسب مشروعك)
- Axios
- REST API

## 📦 Installation

```bash
git clone https://github.com/your-username/student-management-app.git
cd student-management-app
npm install
npm start
